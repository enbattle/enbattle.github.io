# Personal Portfolio Website

A modern, responsive portfolio website built with Next.js 15, React 19, and TypeScript. Features a clean design, dark/light mode, and smooth animations.

Live site here: [https://enbattle.github.io/](https://enbattle.github.io/)

## 🚀 Features

- ⚡️ Next.js 15 with App Router
- 🎨 TailwindCSS for styling
- 🌓 Dark/Light mode support
- ✨ Smooth animations with Framer Motion
- 📱 Fully responsive design
- 🎯 TypeScript for type safety
- 🎨 Modern UI components with Radix UI
- 📝 Contact form functionality
- 🚀 Optimized performance

## 🛠️ Tech Stack

- **Framework:** Next.js 15.2.2
- **Language:** TypeScript
- **Styling:** TailwindCSS
- **UI Components:** Radix UI
- **Animations:** Framer Motion
- **Theme:** next-themes
- **Deployment:** GitHub Pages
